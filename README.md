# CheckLove: página de vendas do Checklist Completo do Casamento

- `index.html`: página de vendas (2 planos + pop-up). Links de checkout (Zuptos) e Pixel ficam em `window.OFERTA`, no começo do arquivo:
  - `PIXEL_ID`: Pixel do Meta (vazio = desligado)
  - `CHECKOUT_PRO`: Plano Pro, R$ 27,90
  - `CHECKOUT_BASICO`: Plano Básico, R$ 14,90 (o clique abre o pop-up antes)
  - `CHECKOUT_UPGRADE`: pop-up, Plano Pro por R$ 19,90
- `img/`: prints das páginas do material.
- Os parâmetros de UTM do anúncio seguem até o checkout.

Repositório público: os PDFs do produto não ficam aqui. Eles são entregues pela plataforma de pagamento.
